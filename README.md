# KANAKK Website

A standalone, static marketing website for KANAKK, separate from the KANAKK application repository.

## Pages
- `index.html` — Home
- `download.html` — Windows download information (installer link intentionally unpublished until the release artifact is verified)
- `plans.html` — Base, Plus and Pro roadmap

## Technology
HTML, CSS and vanilla JavaScript. No build step, package installation, tracking scripts, or runtime server required.

## Local preview
Open `index.html` in a browser, or serve the repository with any static file server.

## Free hosting with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Set the build/deployment source to **GitHub Actions**.
3. Pushes to `main` will deploy through `.github/workflows/pages.yml`.
4. Once the workflow succeeds, use the URL shown in **Settings → Pages**.

The repository must be public for the standard free GitHub Pages offering on GitHub Free.
